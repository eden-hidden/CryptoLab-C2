Ce programme applique le chiffrement de César au texte saisi. Il demande d’abord un message, puis un nombre de décalage. Chaque lettre est décalée dans l’alphabet en conservant sa casse, les espaces, chiffres et signes de ponctuation restent inchangés.

Le programme affiche ensuite le texte chiffré, puis le déchiffre en appliquant le décalage inverse et affiche le message d’origine.

Pour l’utiliser, lance le programme dans un terminal, saisis le texte et le décalage demandés, puis appuie sur Entrée après chaque saisie.
